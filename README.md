# 3D AI Anomaly Detection

Python project for anomaly detection using Machine Learning and 3D visualization.

## Technologies
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

## Features
- Anomaly detection
- 3D data visualization
- Machine learning model
- Data processing

## Description
This project uses the Isolation Forest algorithm to identify anomalous values in a dataset and visualize them in a 3D environment.
